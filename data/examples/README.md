# Examples

Representative, shareable outputs produced by `python scripts/run_demo.py --write-examples`
with the **offline mock model** (they show the format, not real LLM quality):

| File | Content |
|---|---|
| `dev_corvane_packaging.graph_assisted.result.json` | Full `AnalysisResult` for the two-document packaging case |
| `dev_corvane_packaging.graph_assisted.graph.json` | The relationship graph as explicit `{nodes, edges}` |
| `dev_corvane_packaging.graph_assisted.graph.mmd` | Mermaid view of that graph |
| `workflow_*.mmd` | Compiled LangGraph workflows of three strategies |

Mermaid files render on GitHub or at https://mermaid.live.
