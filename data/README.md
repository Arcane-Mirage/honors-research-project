# Datasets

Everything in `data/` is a **benchmark dataset**: documents plus hand-written gold annotations,
described by a `manifest.json`. Experiments (`csr-lab run`, `csr-lab sweep`, `run_demo.py`)
read a dataset through its manifest (`dataset: data/<...>/manifest.json` in a config) and score
the results against the gold.

```
data/
  synthetic/              generated by csr_lab.datasets (committed, checked by the tests)
    text/                 5 cases as .txt; the reference dataset         csr-lab generate-data
    pdf/                  same cases and gold, rendered as PDFs          csr-lab generate-data --pdf
    chunked/              same cases as paragraph-packed chunk files     csr-lab generate-data --chunked paragraph
    chunked_window/       same cases as blind 60-word window chunks      csr-lab generate-data --chunked window --chunk-words 60
    scaled/               (not committed) scaled ablation cases          csr-lab generate-data --scaled N
  <name>/                 an external dataset you add (see below)
```

| Folder | What it is |
|---|---|
| [`../input/`](../input/) | Your own documents for `csr-lab build-graph`: no gold and never scored. Git-ignored. |
| `../outputs/` | Experiment results and the results database. Git-ignored. |
| `../graphs/` | Saved relationship graphs built by `build-graph` / `analyze --graph`. Git-ignored. |
| [`../docs/examples/`](../docs/examples/) | Committed sample outputs for the documentation. |

Do not edit files under `synthetic/` by hand. Change the generator, bump `DATASET_VERSION`
and regenerate. The test suite fails if the committed files differ from the generator output.

## Adding an external dataset

1. Put the documents (UTF-8 `.txt`, text-based `.pdf`, or `.json` with a `text` field) under
   `data/<name>/documents/`. Do not commit files whose licence does not allow redistribution;
   commit a download script instead and git-ignore the documents.
2. Write `data/<name>/manifest.json` in the same format as `synthetic/text/manifest.json`.
   Cases without `ground_truth` can be analysed (`csr-lab analyze`) but not scored.
3. For scored cases, write gold files that validate against `CaseGold` in
   `src/csr_lab/schemas.py`. Annotate them by hand, never from a pipeline's output.
4. Point an experiment at it: `dataset: data/<name>/manifest.json`.
